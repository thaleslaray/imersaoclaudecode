Claude não é um chatbot

O Claude é um assistente de IA criado pela Anthropic — a empresa fundada por ex-líderes da OpenAI. Diferente de chatbots comuns, o Claude foi projetado para ser um parceiro de pensamento: ele não apenas responde perguntas, mas colabora com você em tarefas complexas.

Pense nele como um colega de trabalho extremamente competente que está disponível 24/7 — ele escreve, analisa, pesquisa, programa e cria documentos. E o melhor: ele aprende com o contexto que você dá.

Onde o Claude vive

O Claude está disponível em vários lugares. Nesta imersão vamos explorar os principais:

Os 3 modos do Desktop App

O app desktop do Claude tem três abas, cada uma para um tipo de trabalho:

Chat

Conversas rápidas, brainstorming, perguntas. Como falar com um colega. Inclui voice mode (falar por voz), quick entry (Option+Option no Mac) e captura de tela.

Cowork

Tarefas complexas e autônomas. O Claude trabalha sozinho — pesquisa, analisa documentos, gera relatórios, organiza arquivos. Você delega e ele entrega.

Code

Criação e edição de arquivos. Mesmo sem saber programar, o Claude cria sites, documentos e ferramentas pra você. Inclui o modo YOLO (bypass de permissões — o Claude executa tudo sem pedir confirmação).

Antes de tudo: conecte suas ferramentas

O que é GTD?

Getting Things Done é um método de produtividade criado por David Allen. A ideia central: tire tudo da sua cabeça e organize num sistema confiável. O Claude + Airtable + Google é o sistema perfeito pra isso.

O fluxo: você fala, o Claude organiza, e salva direto nas suas ferramentas — tarefas no Airtable, eventos no Calendar, rascunhos no Gmail.

Passo 1: Crie a base no Airtable

Antes de qualquer coisa, crie uma base vazia no Airtable:

  1. Acesse airtable.com (crie conta gratuita se não tiver)
  2. Clique em "Create a base"
  3. Nomeie como "Meu GTD"
  4. Pronto — a base vazia está criada (3 cliques)

Passo 2: Claude cria a estrutura

Agora o Claude vai criar todas as tabelas dentro da sua base. Cole este prompt no Chat:

Setup GTD no Airtable (faça uma vez)

Já criei uma base chamada "Meu GTD" no Airtable. Crie as seguintes tabelas dentro dela: TABELA 1: "📥 Inbox" Campos: Tarefa (texto) | Data de captura (data) | Processado (checkbox) TABELA 2: "✅ Próximas Ações" Campos: Tarefa (texto) | Contexto (select: @Casa, @Trabalho, @Computador, @Telefone, @Compras) | Prazo (data) | Prioridade (select: Alta, Média, Baixa) | Status (select: A fazer, Em andamento, Concluído) TABELA 3: "📁 Projetos" Campos: Projeto (texto) | Status (select: Ativo, Em pausa, Concluído, Cancelado) | Área (select: Trabalho, Saúde, Família, Financeiro, Pessoal) | Data limite (data) | Próxima ação (texto) TABELA 4: "⏳ Aguardando" Campos: O que estou esperando (texto) | De quem (texto) | Data que pedi (data) | Follow-up (data) TABELA 5: "💡 Algum Dia" Campos: Ideia (texto) | Categoria (select: Viagem, Curso, Negócio, Livro, Outro) | Anotações (texto longo) Pode deletar ou renomear a tabela padrão que veio com a base. Adicione 2-3 itens de exemplo em cada tabela.

💡 Resultado esperado O Claude cria as 5 tabelas com campos tipados (selects, datas, checkboxes), popula com exemplos e está tudo pronto em menos de 1 minuto. Abra o Airtable e confira!

O que é o Cowork?

No bloco anterior você usou o Chat — conversa passo a passo. Agora vamos pro Cowork: você delega uma missão inteira e o Claude trabalha sozinho, por vários passos, sem precisar da sua intervenção.

⚠️ Importante O Cowork funciona apenas no Claude Desktop App (não no web nem no celular). Ele usa os mesmos conectores que você já configurou, mais acesso direto a pastas no seu computador.

Pense assim: no Chat você conversa com o Claude. No Cowork você contrata o Claude pra fazer um trabalho completo.

Exemplo da diferença

Chat: "Me fala sobre o concorrente X" → Claude responde. "E o Y?" → Claude responde. "Faz uma tabela?" → Claude faz. (3 passos manuais)

Cowork: "Analise os concorrentes X, Y e Z. Pesquise na web, compare posicionamento, preços e pontos fracos. Gere um relatório em Excel e salve na pasta." → Claude faz tudo sozinho em 10+ passos.

Como funciona

  1. Abra a aba Cowork no Claude Desktop
  2. Dê acesso a uma pasta no seu computador (o Claude lê e salva arquivos nela)
  3. Descreva a tarefa com clareza
  4. O Claude cria um plano, mostra pra você, e executa
  5. Acompanhe o progresso na barra lateral

Modo YOLO (demo)

No modo normal, o Claude pede permissão antes de cada ação (editar arquivo, rodar comando, etc). O Modo YOLO desativa TODAS essas confirmações — o Claude executa tudo sozinho, sem parar pra perguntar.

Tecnicamente, é ativado com a flag --dangerously-skip-permissions no terminal. O nome já diz: é perigoso. O Claude pode rodar qualquer comando, deletar arquivos, instalar pacotes — tudo sem pedir.

ModoO que faz
defaultPergunta antes de cada ação (o padrão)
acceptEditsAceita edições de arquivo, mas pergunta antes de rodar comandos
planSó analisa e planeja, não faz alterações
YOLO (bypassPermissions)Executa TUDO sem pedir — arquivos, comandos, ferramentas
⚠️ Cuidado O YOLO mode é impressionante de assistir, mas nunca use na sua máquina principal sem proteção. Idealmente use em projetos isolados ou dentro de containers Docker. Vamos ver uma demo controlada agora.

Por que o terminal?

Tudo que você fez hoje no Desktop App também funciona no terminal. A diferença: no terminal você desbloqueia funcionalidades que não existem no app.

FuncionalidadeDesktop AppTerminal
Chat, Cowork, Código✓✓
Conectores (Google, Airtable)✓✓
Skills (criar e instalar)Limitado✓ Completo
Hooks (automações)✗✓
MCP Servers (extensões)Conectores básicos✓ Qualquer MCP
CLAUDE.md (memória do projeto)✗✓
Subagentes✗✓
Custom commands (/review, /test)✗✓

Pense no Desktop App como dirigir automático. O terminal é o câmbio manual — mais poder pra quem aprende a usar. E é no terminal que vamos criar Skills amanhã.

Instalando o Warp

O Warp é um terminal moderno, bonito e com IA embutida. Muito menos intimidador que o Terminal padrão.

  • ✓ Acesse warp.dev/download

  • ✓ Windows: Baixe o instalador, execute, siga os passos
  • ✓ Crie uma conta no Warp (gratuita) ou pule

A tese que muda tudo

Hoje os infoprodutores vendem cursos — 40 aulas ensinando uma metodologia. O aluno assiste, tenta aplicar, muitas vezes desiste.

E se, em vez de ensinar a metodologia, você pudesse entregar a metodologia funcionando? O aluno não precisa aprender cada passo — ele tem um assistente que executa seguindo exatamente o seu método.

Isso é uma Skill.

Curso vs. Skill

Curso: "Aprenda minha metodologia de copywriting em 20 aulas" → o aluno precisa estudar, praticar, errar, tentar de novo.

Skill: "Instale esta Skill e o Claude escreve copy seguindo exatamente minha metodologia" → o aluno tem o resultado imediato.

O que é uma Skill, na prática?

Uma Skill é um conjunto de instruções que ensina o Claude a executar uma tarefa específica de forma consistente. Na prática, é uma pasta com arquivos Markdown que descrevem:

  • O que a Skill faz
  • Quando o Claude deve usá-la
  • As regras e o passo a passo para executar
  • Exemplos de como o resultado deve ficar

Você não precisa programar para criar uma Skill. É texto puro — instruções claras em linguagem natural.

Exemplos reais

SkillO que fazQuem criaria
Gerador de roteirosCria roteiros de Reels seguindo um framework que já performa bemCreator de conteúdo
Analisador de perfilAnalisa um perfil de Instagram e sugere melhorias na bio, destaques e estratégiaSocial media manager
Criador de propostasGera propostas comerciais com escopo, preço e timeline baseado num briefingFreelancer / consultor
Corretor de redaçãoAvalia redações usando critérios do ENEM e dá feedback detalhadoProfessor
Planejador de dietaCria cardápio semanal baseado em restrições e objetivos do clienteNutricionista

Analise estes 3 posts que performaram bem no meu Instagram: Post 1: [cole o texto do post] Post 2: [cole o texto do post] Post 3: [cole o texto do post] Identifique: 1. O padrão de hook (como começa) 2. A estrutura (como desenvolve) 3. O CTA (como termina) 4. O tom de voz 5. O Skill Creator

A Anthropic criou uma ferramenta dentro do próprio Claude para criar Skills via conversa. Você descreve o que quer, o Claude faz perguntas de refinamento e gera a Skill pronta — sem tocar em código.

Passo a passo

1. Defina sua Skill

Antes de começar, pense:

  • Que tarefa você faz repetidamente e gostaria de automatizar?
  • Qual seu método? Existe um passo a passo que você segue?
  • Como é um resultado bom? Você consegue dar exemplos?
💡 Ideias de Skills Roteiro de Reels no seu formato, análise de perfil, proposta comercial, email de follow-up, briefing criativo, plano de aula, avaliação de redação, cardápio semanal, script de vendas...

2. Abra o Skill Creator

No Claude Desktop (Chat) ou no terminal, use este prompt para iniciar:

Prompt

Quero criar uma Skill para o Claude. Me ajude a construí-la passo a passo. A Skill deve: [descreva em uma frase o que ela faz] Exemplo: "Criar roteiros de Reels no formato hook → problema → solução → CTA, seguindo meu tom de voz descontraído e direto." Me faça as perguntas necessárias para construir uma Skill completa e profissional.

3. Responda às perguntas

O Claude vai perguntar sobre:

  • O que a Skill deve fazer exatamente
  • O formato do resultado esperado
  • Regras e restrições
  • Exemplos de resultado bom
  • Tom de voz e estilo

Responda com detalhes — quanto mais contexto, melhor a Skill.

4. Receba sua Skill

O Claude gera um arquivo ZIP com a estrutura completa da Skill. Baixe o arquivo.

5. Instale

Vá em Configurações > Personalizar e clique em "Enviar habilidade". Selecione o ZIP. Pronto — sua Skill aparece na lista.

6. Teste

Abra um novo chat e faça um pedido que ativaria sua Skill. O Claude vai detectar automaticamente que deve usá-la.

MCP — Model Context Protocol

Conecte o Claude a qualquer ferramenta externa: banco de dados, APIs, navegador, CRM, planilhas do Google, Notion, Slack. MCP é o que transforma o Claude de assistente em automação real.

Hooks

Automatize ações antes e depois de cada coisa que o Claude faz. Exemplo: toda vez que o Claude edita um arquivo, roda um verificador automaticamente. É como colocar o Claude no piloto automático com guardrails.

Subagentes

O Claude cria cópias de si mesmo para trabalhar em paralelo. Delega subtarefas, coleta resultados e monta a entrega final. Um Claude virando um time inteiro.
