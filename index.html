Claude não é um chatbot

O Claude é um assistente de IA criado pela Anthropic — a empresa fundada por ex-líderes da OpenAI. Diferente de chatbots comuns, o Claude foi projetado para ser um parceiro de pensamento: ele não apenas responde perguntas, mas colabora com você em tarefas complexas.

Pense nele como um colega de trabalho extremamente competente que está disponível 24/7 — ele escreve, analisa, pesquisa, programa e cria documentos. E o melhor: ele aprende com o contexto que você dá.

O que é GTD?

Getting Things Done é um método de produtividade criado por David Allen. A ideia central: tire tudo da sua cabeça e organize num sistema confiável. O Claude + Airtable + Google é o sistema perfeito pra isso.

O fluxo: você fala, o Claude organiza, e salva direto nas suas ferramentas — tarefas no Airtable, eventos no Calendar, rascunhos no Gmail.

O que é o Cowork?

No bloco anterior você usou o Chat — conversa passo a passo. Agora vamos pro Cowork: você delega uma missão inteira e o Claude trabalha sozinho, por vários passos, sem precisar da sua intervenção.

⚠️ Importante O Cowork funciona apenas no Claude Desktop App (não no web nem no celular). Ele usa os mesmos conectores que você já configurou, mais acesso direto a pastas no seu computador.

Pense assim: no Chat você conversa com o Claude. No Cowork você contrata o Claude pra fazer um trabalho completo.

Exemplo da diferença

Chat: "Me fala sobre o concorrente X" → Claude responde. "E o Y?" → Claude responde. "Faz uma tabela?" → Claude faz. (3 passos manuais)

Cowork: "Analise os concorrentes X, Y e Z. Pesquise na web, compare posicionamento, preços e pontos fracos. Gere um relatório em Excel e salve na pasta." → Claude faz tudo sozinho em 10+ passos.

Como funciona

  1. Abra a aba Cowork no Claude Desktop
  2. Dê acesso a uma pasta no seu computador (o Claude lê e salva arquivos nela)
  3. Descreva a tarefa com clareza
  4. O Claude cria um plano, mostra pra você, e executa
  5. Acompanhe o progresso na barra lateral

Modos de permissão no terminal

No Desktop App, o YOLO é um toggle nas Configurações. No terminal, você tem 4 modos de permissão — e pode alternar entre eles a qualquer momento com Shift+Tab:

ModoO que faz
defaultPergunta antes de cada ação (o padrão)
acceptEditsAceita edições de arquivo, mas pergunta antes de rodar comandos
planSó analisa e planeja, não faz alterações
YOLO (bypassPermissions)Executa TUDO sem pedir — arquivos, comandos, ferramentas

Para iniciar o Claude Code direto no modo YOLO, use a flag --dangerously-skip-permissions. O nome já diz: é perigoso. O Claude pode rodar qualquer comando, deletar arquivos, instalar pacotes — tudo sem pedir.

Atalho: alias "cc" para modo YOLO

Pra não digitar esse comando enorme toda vez, crie um alias:

Mac / Linux (Zsh) echo 'alias cc="claude --dangerously-skip-permissions"' >> ~/.zshrc && source ~/.zshrc
Windows (PowerShell) if (!(Test-Path $PROFILE)) { New-Item $PROFILE -Force }; Add-Content $PROFILE 'function cc { claude --dangerously-skip-permissions @args }'; . $PROFILE

A partir de agora, basta digitar cc no terminal pra abrir o Claude em modo YOLO.

⚠️ Modo YOLO = sem freio O Claude vai executar tudo sem perguntar — criar arquivos, instalar coisas, rodar comandos. Use com consciência. Pra tarefas delicadas, abra com claude normal.

Problemas comuns

Perguntas que surgiram na aula — provavelmente você vai ter as mesmas dúvidas:

ProblemaSolução
"Cowork não aparece no meu app" Cowork exige o plano Pro (US$20/mês) e só funciona no Desktop App. Não aparece no chat web.
"Não tem pra Linux" O Desktop App só tem pra Mac e Windows. Mas o Claude Code (terminal) funciona em Linux normalmente.
"Mac aquecendo muito" Normal com modelos grandes. Feche apps desnecessários, especialmente Chrome com muitas abas. O ventilador pode ligar — não se preocupe.
"Agent Driven vs Classic no Warp?" Escolha Classic Terminal. O modo Agent Driven usa a IA do Warp, que conflita com o Claude Code.
"Sonnet ou Opus?" Sonnet pro dia a dia (rápido, barato). Opus pra tarefas complexas que precisam de mais raciocínio. No plano Pro, você tem os dois.
"Posso cancelar o ChatGPT?" Depende do seu uso. Claude é melhor pra código, análise e tarefas longas. ChatGPT ainda tem vantagem em geração de imagem e busca na web. Teste os dois por um mês antes de decidir.
"Como ver meu consumo?" No terminal: /usage. No app: menu do perfil → Usage. O plano Pro tem limite generoso mas não é ilimitado.
"Plugin instalado mas não apareceu" Use /reload-plugins no Cowork. Se persistir, feche e reabra o Claude Desktop.
"Claude parou de responder" No Desktop, aguarde ou recarregue a conversa. No terminal: Ctrl+C para cancelar a ação atual e tente novamente.
"Limite de uso atingido" Normal no plano Pro — o limite reseta em ~3 horas. Enquanto espera, use o modelo Haiku (mais leve) ou considere o plano Max se precisar de mais volume.
"Terminal não reconhece o comando" Feche e reabra o terminal após a instalação. No Mac, rode source ~/.zshrc. No Windows, abra um novo PowerShell.

Consulta

  1. Precisa do plano pago?

    Pra aproveitar de verdade, sim. O plano Pro ($20/mês ~R$110) libera Skills, Cowork, Claude Code e ~80 mensagens a cada 5 horas. O Free é muito limitado. O Max ($100-200/mês) multiplica os limites 5x ou 20x — ideal pra uso intenso.

  2. Pago mais alguma coisa pelos plugins?

    Não. Plugins, conectores (Google, Airtable, Notion) e Skills estão todos inclusos no plano Pro. Você não paga por plugin individual.

  3. Dá pra ver quanto estou consumindo?

    Sim. No Desktop App: avatar > Configurações > Uso. No terminal: claude --usage. O limite reseta a cada 5 horas, não a cada 24h.

  4. Qual a diferença entre plugin e skill?

    Skill = receita que o Claude segue automaticamente. Funciona em qualquer lugar (Desktop, web, terminal).
    Plugin = pacote que pode conter skills + comandos + agentes + integrações. Funciona só no terminal e Cowork.

    Analogia: skill é uma receita de bolo. Plugin é um kit de confeitaria com receitas + utensílios.

  5. Posso transformar meu curso numa Skill?

    Sim — esse é o tema do Dia 2. Você extrai a metodologia do seu curso (passo a passo, regras, framework) e transforma em instruções. Limite prático: mantenha o arquivo com menos de 500 linhas. Cursos extensos viram múltiplas Skills focadas.

  7. É seguro dar acesso aos meus dados?

    Sim, com boas práticas. O Cowork roda em sandbox — só acessa a pasta que você autorizar. O terminal pede confirmação antes de cada ação. Anthropic não usa dados de planos pagos (Pro/Max/Team) pra treinar modelos. Não cole senhas em prompts, use projetos separados por cliente.

  8. Sonnet ou Opus? Qual modelo usar?

    Sonnet 4.6 pra 90% das tarefas. É o padrão, rápido e excelente. Opus é mais inteligente mas lento e só disponível no plano Max ($100+/mês). Regra: se Sonnet resolve, fique com Sonnet.

  9. Posso cancelar o ChatGPT?

    Claude é melhor em escrita longa, análise profunda e coding agêntico. ChatGPT é melhor em geração de imagem (DALL-E), Custom GPTs e automações. Se seu foco é escrita e automação — Claude sozinho resolve. Se usa muito imagem ou GPTs customizados — mantenha os dois.

  10. Lovable/Antigravity/OpenClaw — ainda preciso?

    Lovable/Antigravity: ainda fazem sentido pra MVP rápido sem terminal. Migre pro Claude Code quando precisar de controle total.
    OpenClaw: resolve problema diferente (orquestração de agentes). Claude Code complementa, não substitui.

  11. Skills de terceiros são confiáveis?

    Skills da Anthropic (anthropics/skills) são confiáveis. Skills do skills.sh têm código aberto — você pode inspecionar. No Desktop, uma skill não pode acessar seus dados nem apagar arquivos por conta própria.

  12. Plugins do Desktop funcionam no Terminal?

    Skills sim, plugins não diretamente. Skills são compartilhadas — instale num, funcione no outro. Plugins são específicos do Claude Code/Cowork.

  13. Funciona no VS Code?

    Sim — de duas formas. Extensão oficial "Claude Code for VS Code" (painel visual, diffs inline) ou pelo terminal integrado (Cmd+` → digita claude). O Warp é recomendado pra iniciantes pela interface visual, mas o Claude Code roda igual em qualquer terminal. O "cérebro" é o mesmo em todos.

  14. O Warp é pago?

    O terminal Warp é gratuito. Ele cobra só pela IA própria dele (plano Build ~$20/mês), que você não precisa. O que é pago é a assinatura do Claude Pro ($20/mês). Resumo: Warp grátis + Claude Pro pago = tudo funcionando.

  15. Meus projetos ficam no PC ou na nuvem?

    100% local. Arquivos criados ficam na pasta do seu computador. O Claude não sobe nada pra nuvem da Anthropic. Histórico de conversas fica nos servidores (30 dias no Pro), mas arquivos e código são seus, na sua máquina. Planos pagos não usam seus dados pra treinar modelos.

  16. Como falar por voz no terminal?

    O Claude Code tem voice mode nativo — digite /voice e use a barra de espaço pra falar (push-to-talk). Gratuito. Alternativas externas: Spokenly (Mac, grátis) ou Wispr Flow (Windows, ~$15/mês). São apps que convertem voz em texto em qualquer campo — fale e o texto vai direto pro terminal.

  17. O Claude acessa o Meta Ads?

    Não diretamente. Mas com integração MCP (Windsor.ai, Adzviser, Composio), o Claude acessa dados ao vivo das campanhas — ROAS, CPA, CTR. Pode gerar relatórios, sugerir otimizações e até pausar anúncios. Pra automação 24/7 (triggers, webhooks), ainda precisa de N8N/Make em paralelo.

A tese que muda tudo

Hoje os infoprodutores vendem cursos — 40 aulas ensinando uma metodologia. O aluno assiste, tenta aplicar, muitas vezes desiste.

E se, em vez de ensinar a metodologia, você pudesse entregar a metodologia funcionando? O aluno não precisa aprender cada passo — ele tem um assistente que executa seguindo exatamente o seu método.

Isso é uma Skill.

Curso vs. Skill

Curso: "Aprenda minha metodologia de copywriting em 20 aulas" → o aluno precisa estudar, praticar, errar, tentar de novo.

Skill: "Instale esta Skill e o Claude escreve copy seguindo exatamente minha metodologia" → o aluno tem o resultado imediato.

🎯 Pense no seu produto Pense no seu produto ou serviço principal. Se você tem um método, framework ou processo que ensina — isso pode virar uma Skill.

Exemplos:
  • Seu curso de copywriting → Skill que escreve copy no seu método
  • Seu processo de consultoria → Skill que faz diagnóstico seguindo seus critérios
  • Sua metodologia de gestão → Skill que organiza projetos do seu jeito
  • Seu framework de vendas → Skill que gera scripts seguindo sua abordagem

A pergunta é simples: o que você ensina que poderia ser executado automaticamente?

O que é uma Skill, na prática?

Uma Skill é um conjunto de instruções que ensina o Claude a executar uma tarefa específica de forma consistente. Na prática, é uma pasta com arquivos Markdown que descrevem:

  • O que a Skill faz
  • Quando o Claude deve usá-la
  • As regras e o passo a passo para executar
  • Exemplos de como o resultado deve ficar

Você não precisa programar para criar uma Skill. É texto puro — instruções claras em linguagem natural.

O Skill Creator

A Anthropic criou uma ferramenta dentro do próprio Claude para criar Skills via conversa. Você descreve o que quer, o Claude faz perguntas de refinamento e gera a Skill pronta — sem tocar em código.

Passo a passo

1. Defina sua Skill

Antes de começar, pense:

  • Que tarefa você faz repetidamente e gostaria de automatizar?
  • Qual seu método? Existe um passo a passo que você segue?
  • Como é um resultado bom? Você consegue dar exemplos?
💡 Ideias de Skills Roteiro de Reels no seu formato, análise de perfil, proposta comercial, email de follow-up, briefing criativo, plano de aula, avaliação de redação, cardápio semanal, script de vendas...

2. Quatro formas de criar uma Skill

No Claude Desktop, vá em Personalizar > Habilidades (sidebar esquerda) e clique no botão "+" no topo. Você verá 3 opções — e a quarta é pelo terminal:

⚠️ Pré-requisito (somente Desktop App) Em Configurações > Capacidades, ative "Execução de código e criação de arquivos". Sem isso, as Skills não funcionam no Desktop.

Opção A: "Criar com o Claude" (Desktop)

Abre o Skill Creator no modo Cowork. O Claude te faz perguntas, refina e gera a Skill completa. Melhor para: quem quer conversar e iterar até ficar perfeito.

Opção B: "Escreva as instruções da skill" (Desktop)

Abre um formulário com 3 campos: Nome, Descrição e Instruções. Cole suas instruções direto. Melhor para: quem já sabe o que quer e quer rapidez.

Opção C: "Fazer upload de uma habilidade" (Desktop)

Envie um arquivo .zip ou .skill com a Skill pronta. Melhor para: instalar Skills que alguém compartilhou com você.

Opção D: Skill Creator via Terminal (Claude Code)

O mesmo Skill Creator, mas direto no Warp. Melhor para: quem já está trabalhando no terminal e quer criar sem sair dele.

Primeiro, instale o Skill Creator (só precisa fazer uma vez):

Terminal — Instalação npx skills add anthropics/skills --skill skill-creator

Depois, use:

Terminal — Uso /skill skill-creator

3. Como funciona o Skill Creator (Opções A e D)

O Skill Creator é uma meta-skill oficial da Anthropic. Tanto pela Opção A (Desktop) quanto pela D (Terminal), o fluxo é o mesmo:

  1. Você descreve o que a Skill deve fazer
  2. O Claude faz perguntas de refinamento (formato, regras, tom de voz, exemplos)
  3. Ele gera a Skill completa
  4. A Skill é instalada automaticamente na sua lista

Dia 2 · FAQ
Perguntas sobre Skills.
9 dúvidas respondidas com pesquisa aprofundada
Consulta

  1. Qual a diferença entre Plugin e Skill?

    Skill = receita de comportamento (SKILL.md). Claude ativa sozinho quando relevante. Funciona em Chat, Cowork e Terminal.
    Plugin = pacote que pode conter skills + comandos + agentes + hooks + integrações MCP. Funciona só no Terminal e Cowork.

    Analogia: skill é uma receita. Plugin é um kit de cozinha (receitas + utensílios + ingredientes). Podem coexistir — um plugin pode conter skills dentro dele.

  2. Como colocar MEU conhecimento dentro de uma Skill?

    Use o Skill Creator (Opção A ou D do Bloco 2). Quando ele perguntar sobre seu método, explique em detalhes: seu passo a passo, regras, tom de voz e exemplos de resultado bom. O Skill Creator organiza tudo automaticamente — cria as pastas templates/, examples/ e reference/ pra você. Quanto mais contexto você der na conversa, melhor a Skill. Dica: cole trechos do seu curso ou framework direto no chat e peça pra ele incorporar.

  3. Skills do Desktop funcionam no Terminal e vice-versa?

    Skills globais sim. Instaladas em Personalizar > Habilidades, funcionam em Chat, Cowork e Terminal. Skills dentro de plugins funcionam só onde o plugin está instalado. Se quiser a mesma skill nos dois, instale nos dois.

  4. Skills de terceiros são seguras?

    Uma skill é só texto — instruções que o Claude segue. Ela não executa código automaticamente nem acessa dados sem permissão. No Desktop, roda em sandbox. No terminal, Claude pede confirmação antes de cada ação. Pra verificar: leia o SKILL.md antes de instalar — é texto puro, legível. Skills do anthropics/skills são revisadas pela Anthropic.

  5. Posso vender Skills como produto?

    Sim. O conteúdo que você escreve é seu. Distribua como ZIP por Hotmart/Gumroad, marketplace (skills.sh, ClaudeSkills.ai), ou hospedado (cliente acessa via link sem ver o código). Já existe gente vendendo skills como infoproduto — venda única, assinatura ou implementação + retainer.

  6. Skills instaladas consomem tokens?

    Quase nada. Na inicialização, Claude lê só nome + descrição (~50-100 tokens cada). O conteúdo completo só carrega quando a skill é ativada. Ter 30 skills instaladas adiciona ~3000 tokens de overhead — irrelevante. Instale sem medo.

  7. Uma Skill pode chamar outra?

    Não diretamente, mas Claude usa múltiplas skills na mesma conversa automaticamente. Se você pedir "crie uma proposta e depois gere os posts de divulgação", ele pode ativar a skill de propostas e a skill de conteúdo na sequência. É composição implícita — você não precisa orquestrar.

  8. Dá pra criar Skill pelo Cowork (sem terminal)?

    Sim, e é o caminho mais fácil. No Cowork, diga: "Me ajude a transformar esse processo em uma skill reutilizável." Claude usa o Skill Creator internamente, te faz perguntas, gera o SKILL.md e instala automaticamente. Sem terminal, sem editar arquivos. Vários criadores fazem isso em menos de 5 minutos.

  9. Que tipo de Skill posso criar pro meu negócio?

    Exemplos reais do público desta imersão: Skill de proposta comercial (consultor), planejamento de conteúdo Instagram (social media), diagnóstico de tráfego pago (gestor), onboarding de cliente (agência), roteiro de vendas (closer), diagramação de apostilas (professor), análise SWOT (estrategista).
